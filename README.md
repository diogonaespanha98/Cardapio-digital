# Cardápio Digital

Cardápio digital responsivo para restaurantes e lanchonetes.

## Funcionalidades

- Layout responsivo
- Categorias de produtos
- Fotos dos produtos
- Integração com WhatsApp
- Compatível com QR Code

## Tecnologias

- HTML5
- CSS3
- JavaScript
